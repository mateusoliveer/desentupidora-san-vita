# Desentupidora SanVita (site demo)

Página única, estática, focada em conversão (WhatsApp e ligação).
Atendimento 24 horas em Aracaju e região.

> Site de demonstração. Textos e depoimento são exemplos.

## Como publicar no GitHub Pages

1. Crie o repositório `desentupidora-san-vita` no GitHub.
2. Envie `index.html` e `README.md` (Add file → Upload files).
3. Vá em Settings → Pages.
4. Em Source, escolha Deploy from a branch, branch `main`, pasta `/ (root)`.
5. O site fica em `https://SEU-USUARIO.github.io/desentupidora-san-vita/`.

## Personalização

- Número do WhatsApp: variável `NUM` no final do `index.html`.
- Textos, serviços e FAQ: edite direto no HTML.
